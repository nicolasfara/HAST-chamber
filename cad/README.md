# CAD

Mechanical design of the HAST chamber (enclosure, fixtures, mounts).

## Layout

| Path        | Content                                                         |
|-------------|-----------------------------------------------------------------|
| `*.FCStd`   | FreeCAD source models (the source of truth)                     |
| `exports/`  | Manufacturing exports (STEP, STL, 3MF, DXF) generated from them |

Keep exports in sync with the source models when committing a change.
